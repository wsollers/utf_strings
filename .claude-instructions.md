#### Testing & Quality (CRITICAL)

#### Final Validation (CRITICAL)
9. ✅ **License headers**: All new C++ files include BSD 2-Clause header
10. ✅ **Git cleanliness**: No untracked files, proper commit messages

**🚫 NEVER push if ANY check fails - fix all issues first!**

### C++23 Idioms to Emphasize
- Use `concepts` instead of SFINAE for template constraints
- Prefer `std::expected` for fallible operations over exceptions
- Leverage `constexpr`/`consteval` for compile-time computation
- Use structured bindings for multiple return values
- Employ ranges and views for algorithm composition
- Use `std::string_view` and `std::span` for non-owning references
