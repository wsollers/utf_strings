# Performance Analysis

This directory contains performance analysis files generated by the CI pipeline.

Files generated here include:
- `index.html` - Main performance dashboard
- `detailed_benchmark.json` - Comprehensive benchmark results
- `benchmark_results.csv` - CSV format benchmark data
- `benchmark_console.txt` - Console output from benchmarks
- `system_info.txt` - System information for benchmark context
- `flamegraph.svg` - Interactive flame graph (when available)
- `perf.script` - Raw perf data (when available)

These files are automatically updated on each push to the main branch.
