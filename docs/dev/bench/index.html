Performance tracking over time for UTF Strings library

📊 Performance Tracking

Historical benchmarks are managed by GitHub Actions
Performance data is automatically collected and stored in the gh-pages branch for trend analysis.

Historical benchmark charts will be available here once multiple benchmark runs have been collected. The system tracks:

  • UTF-8/16/32 conversion performance
  • Validation algorithm speed
  • Memory usage patterns
  • Performance regression detection

📈 GitHub Actions Integration

Benchmark data is collected via the benchmark-action/github-action-benchmark action and stored automatically.

Charts will appear here as benchmark data accumulates over multiple CI runs.
