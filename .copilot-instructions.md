### Modern C++23 Patterns to Follow
1. **Input validation with modern error handling**:
```cpp
auto process_utf8(std::u8string_view input) -> std::expected<result_type, error_code> {
    if (input.empty()) return std::unexpected(error_code::empty_input);
    if (!is_valid_utf8(input)) return std::unexpected(error_code::invalid_utf8);
    // ... process
}
```

2. **Use concepts for template constraints**:
```cpp
template<utf_encoding T>
requires std::same_as<T, char8_t> || std::same_as<T, char16_t>
auto convert_encoding(std::basic_string_view<T> input) -> std::string;
```

3. **Structured bindings for multiple returns**:
```cpp
auto [result, error] = try_convert_utf8_to_utf16(input);
if (error) { /* handle error */ }
```

4. **Constexpr and consteval for compile-time operations**:
```cpp
consteval auto max_utf8_sequence_length() -> size_t { return 4; }
constexpr auto is_ascii(char8_t c) -> bool { return c < 0x80; }
```

5. **Always include corresponding unit tests**:
```cpp
// For every function you generate, also provide:
TEST(Utf8ConversionTest, HandlesValidSequences) {
    auto result = convert_utf8_to_utf16(u8"Hello, 世界!");
    ASSERT_TRUE(result.has_value());
    EXPECT_EQ(result.value(), u"Hello, 世界!");
}
```
